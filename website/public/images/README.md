# Micade Website Images

Place website image assets in this folder.

Use them in the Next.js site with paths such as:

- `/images/hero-image.jpg`
- `/images/micade-logo.svg`
- `/images/service-preview.png`

Recommended folders as the image library grows:

- `brand/` for logos and brand assets.
- `hero/` for homepage and page hero images.
- `services/` for service visuals.
- `projects/` for portfolio and case-study images.
- `academy/` for learning content.

Use descriptive filenames, optimized formats such as WebP or AVIF where practical, and include alt text when adding images to page components.
