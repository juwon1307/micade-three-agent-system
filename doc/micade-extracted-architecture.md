## Project Identity

Micade is intended to become a globally respected technology, education, AI, software, and digital growth company.

The project should not be treated as a simple website build. The documents define Micade as a long-term company-building effort where brand, business, product, technology, content, marketing, operations, and growth must work together as one ecosystem.

## Governing Principle

The strongest principle across the documents is:

Documentation before implementation.

This means the project should not jump directly into website design or code. Important decisions should first be captured in professional documents that can guide designers, developers, partners, future employees, and investors.

## Current Phase

The roadmap places Micade in Phase 1: Build the Company.

Phase 1 should be completed before serious website design or development begins.

The Phase 1 deliverables are:

1. Micade Brand Guidelines v1.0
2. Micade Company Blueprint v1.0
3. Micade Business Plan
4. Micade Website Technical Specification v1.0

The roadmap states that Brand Guidelines and Company Blueprint have already been started, while the Business Plan and Website Technical Specification are still pending.

- Work one section at a time.

## Practical Use For The Code Project

The current TypeScript project should evolve from a generic three-agent prototype into a Micade company-building assistant.

Recommended agent roles:

- Manager Agent: routes work, enforces chapter-by-chapter progress, and prevents jumping ahead.
- Brand Strategy Agent: supports brand guidelines, positioning, voice, values, and identity.
- Business Architecture Agent: supports company blueprint, revenue model, services, departments, customer journey, and policies.
- Enterprise Architecture Agent: keeps all documents aligned with Micade's governing architecture.
- Technical Specification Agent: turns approved business and brand decisions into website and product specifications.
- Writer Agent: turns approved notes into professional Micade documentation.

The current three-agent system can be kept as the foundation, but the instructions should be updated so the agents operate according to the Micade architecture.
