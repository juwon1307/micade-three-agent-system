# Micade Company Blueprint v1.0 Working Flow

## Purpose

This flow creates Micade Company Blueprint v1.0 one section at a time.

It uses the approved Micade Brand Guidelines direction as the foundation for business architecture decisions.

## Section Order

1. Company Foundation
2. Services and Offer Model
3. Operating Model
4. Growth Model

## Step 1: Company Foundation

Command:

```bash
npm run company:foundation
```

Local starter draft command:

```bash
npm run company:foundation:starter
```

Prompt inspection command:

```bash
npm run company:foundation:dry-run
```

Expected output:

- Company category
- Company purpose
- First priority audience
- First launch segment
- Initial offer categories
- Business direction
- Operating principles
- Success measures
- Approval questions

Current saved draft:

`doc/Micade_Company_Blueprint_v1.0_Company_Foundation.md`

## Approval Rule

The project should not continue to Services and Offer Model until the Company Foundation section is reviewed and approved.
