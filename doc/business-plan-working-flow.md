# Micade Business Plan Working Flow

## Purpose

This flow creates the Micade Business Plan one section at a time.

It uses the approved Micade Brand Guidelines and Company Blueprint as the foundation for business planning.

## Section Order

1. Executive Summary
2. Market and Customer Strategy
3. Revenue Model
4. Execution Roadmap

## Step 1: Executive Summary

Command:

```bash
npm run business:summary
```

Local starter draft command:

```bash
npm run business:summary:starter
```

Prompt inspection command:

```bash
npm run business:summary:dry-run
```

Expected output:

- Business summary
- Starting market focus
- Initial offers
- Business model
- Growth strategy
- Competitive direction
- Early success measures
- Risks
- Approval questions
